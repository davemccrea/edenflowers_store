# AGENTS.md

OpenCode's entry point for this repository. The canonical project instructions
live in `CLAUDE.md` and are loaded through the `instructions` field in
`opencode.jsonc`. Follow them for every task.

Harness details that differ from Claude Code:

- Skills live in `.claude/skills` (project) and `~/.claude/skills` (global).
  OpenCode discovers both automatically. Load one by its directory ID with the
  `skill` tool, e.g. `ash-framework`, `grilling`, `elixir-otp`.
- When `CLAUDE.md` names a Claude-only tool, use the OpenCode equivalent:
  - `AskUserQuestion` → the `question` tool.
  - `EnterWorktree` → the `opencode` tools in Code Mode
    (`tools.opencode.session_move`, `tools.opencode.worktree_*`).
- MCP servers are configured under `mcp.servers` in `opencode.jsonc`: Tidewave
  (the live dev server), Backlog (tasks under `backlog/`, reached through
  Code Mode as `tools.backlog.*`), plus the hosted MailerLite and Cloudflare
  servers, which use OAuth tokens kept outside the config (`/mcps` to sign
  in). A worktree's `.opencode/opencode.json` (generated by
  `.config/wt.toml`) repoints Tidewave at that worktree's dev server port.
